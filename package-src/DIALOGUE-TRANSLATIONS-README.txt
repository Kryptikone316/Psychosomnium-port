Psychosomnium (SF3500 port): optional dialogue translations
============================================================

What this is
  The port's menus are translated in the main package. This download adds the GAME'S DIALOGUE in the other
  languages of TreeFrogUI: Deutsch, Espanol, Francais, Italiano, Polski, Portugues (BR), Turkce, Russian,
  Japanese, Chinese (Simplified) and Arabic. The English dialogue is not in this file: it always comes from your
  own copy of the game, and these files only hold the translated lines.

How to install
  Copy this zip (as it is) into the port's "lang" folder, next to the .pak files:
      roms/ports/psychosomnium/lang/psychosomnium-dialogue-translations.zip
  (or unpack the .script files into that folder). Then pick a language in Settings. The Language row tells you
  when the dialogue translation is not installed.

Credits and terms
  Psychosomnium is a game by Cactus (2008), music by Zabutom, splash screen by Cow. These translations are an
  unofficial fan translation of its dialogue, made for this port; they are a derivative of the original text and no
  rights to the game are claimed. If Cactus (or anyone representing the game) asks for them to be taken down, they
  will be removed.
  The translations were written by the port author without review by native speakers: expect rough edges, and
  corrections are welcome.
